# Tooplay iPhone · iPad 0.3.2 (빌드 3)

두 탭을 제공하는 iOS 16 이상용 SwiftUI 앱입니다.

- **내 기기 영상**: 파일 앱에서 MP4/MOV 등 AVPlayer 지원 영상을 가져와 재생합니다. UTF-8·UTF-16(BOM)·EUC-KR SRT/VTT 외부 자막, 탐색, 재생/일시정지, 음량을 지원합니다. Cast 버튼으로 Chromecast를 선택하고 **이 영상을 TV로**를 누르면 AVFoundation 720p 프리셋과 30fps 영상 구성을 사용해 전체 파일을 미리 변환한 뒤 HTTP Range로 전송합니다. 변환이 끝나기까지 기다려야 하며 원본과 변환본을 둘 공간이 필요합니다. 준비를 취소하거나 실패하면 기존 로컬 재생을 복원합니다.
- **컴퓨터 연결**: Tooplay 데스크톱 0.3.0의 **휴대폰 연결**에 표시된 Wi-Fi 주소와 6자리 코드를 입력합니다. 재생·일시정지·10초 이동·위치 이동·음량·자막·컴퓨터에서 Chromecast로 전송·전송 취소·영상 닫기를 조작합니다. 컴퓨터 파일을 임의로 탐색하거나 업로드하지 않습니다.

내 기기 영상을 TV로 보낼 때는 앱을 열어 두어야 합니다. 전송 중 자동 화면 잠금을 막으며, 사용자가 화면을 잠그거나 앱을 배경으로 보내면 로컬 영상 서버와 Cast 전송을 중단합니다. 돌아온 뒤 전송 버튼으로 이어서 보낼 수 있습니다. 컴퓨터 연결 모드는 휴대폰 화면이 꺼져도 컴퓨터가 재생을 담당하므로 계속 재생됩니다.

## 0.3.2 전체화면과 화면 비율

영상을 연 뒤 제목 옆 **전체화면**을 누르면 앱의 전체 화면으로 재생합니다. **닫기**를 누르면 원래 화면으로 돌아옵니다. 화면을 전환해도 같은 영상을 계속 사용하므로 재생 위치와 자막 상태를 유지합니다. 기기를 가로·세로로 돌리면 화면에 맞춰 배치합니다.

- **원본 비율**: 영상 비율을 유지하고 영상 전체를 표시합니다. 영상과 디스플레이 비율이 다르면 검은 여백이 생길 수 있습니다.
- **화면 채우기**: 영상 비율을 유지하면서 화면을 채웁니다. 화면 밖으로 나가는 가장자리는 일부 잘릴 수 있으며, 영상을 가로나 세로로 늘려 왜곡하지 않습니다.

비율 옵션은 일반 화면과 전체화면에서 함께 적용되고 다음 실행에도 기억합니다. 이 옵션은 iPhone·iPad의 로컬 영상 표시용이며 Chromecast 화면 비율을 바꾸지 않습니다.

전체화면에서는 재생·일시정지, 시간 이동, 자막 표시·숨김을 사용할 수 있습니다. 재생 중 조작부는 약 4초 뒤 숨겨지며, 영상을 한 번 탭하면 다시 나타납니다. 탭으로 직접 숨길 수도 있습니다. 일시정지하거나 탐색 슬라이더를 잡고 있는 동안에는 자동으로 숨기지 않습니다. 자막은 조작부 위에 배치하고 조작부가 숨겨져도 계속 표시합니다.

0.3.1의 소리 재생 수정은 유지했습니다. 0.3.2도 실제 iPad에 설치하고 기기 명령으로 실행을 확인했습니다. 실제 영상 레이어의 비율·재생 유지 검사와 iPad 시뮬레이터 전체화면 UI 검사가 통과했습니다. UI 검사는 별도 시험용 앱에서 영상을 미리 열고 실제 재생·화면 코드를 사용했습니다. 시스템 파일 선택창의 전체 조작 과정과 실제 iPad의 전체화면 손동작 검증은 포함하지 않습니다.

## 0.3.1 소리 재생 수정

- 로컬 영상 재생을 시작하거나 다시 재생할 때 오디오 세션을 `playback`·`moviePlayback`으로 설정하고 활성화합니다. iPhone·iPad의 무음 모드에서도 영상 음성을 재생하는 정책입니다. 영상 닫기와 백그라운드 진입 때는 재생을 멈춘 뒤 오디오 세션을 해제합니다.
- 기존 `Tooplay-test-video.mp4`는 음성 트랙 자체가 무음인 시험 파일입니다. 소리 확인에는 새 `Tooplay-audio-test.mp4`를 사용하세요. 30초 동안 440Hz 시험음이 들어 있습니다. 재생 전 기기 음량을 낮게 설정한 뒤 필요한 만큼 올리세요.
- iPad 시뮬레이터에서 오디오 정책·음성 데이터 디코딩 검사와 기존 영상·자막 재생 검사, 총 2개가 실패 없이 통과했습니다. 디코딩한 16비트 PCM의 최대 절댓값은 2979였습니다. 이 결과는 설정과 파일의 음성 데이터 검증입니다. 별도로 2026-11-05에 사용자가 설치된 0.3.1을 iPad에서 직접 재생해 소리가 정상적으로 나온다고 확인했습니다. 이 청취 확인은 자동화된 스피커 출력 계측과 구분합니다.

## 개인 기기에 설치

이 폴더에는 실제 `Tooplay.xcodeproj`가 들어 있습니다. 0.3.0에서 Xcode 27.2로 Simulator용 앱과 iPhone/iPad 기기용 Release 아카이브를 모두 빌드했습니다. 당시 개인 서명 빌드를 연결된 **iPad Pro 11형(4세대, iPadOS 27.2)에 설치했으며**, 개발자 인증서를 신뢰한 뒤 사용자 확인과 기기 실행 명령으로 첫 실행을 검증했습니다. 0.3.1 소리 수정판도 같은 iPad에 업데이트 설치했습니다. 2026-11-05에 사용자가 수정판을 직접 실행·재생한 뒤 소리가 정상적으로 나온다고 확인했습니다.

이 저장소는 iPhone·iPad 앱의 소스 프로젝트를 제공합니다. 기기에 설치할 때 본인의 Apple 계정과 기기로 서명합니다. 프로젝트의 Team 설정은 비워 두었으며 개인 서명 키와 등록 기기의 프로비저닝 프로파일은 포함하지 않습니다.

1. Mac App Store에서 Xcode를 설치하고 한 번 실행해 iOS 플랫폼 도구를 설치합니다.
2. `Tooplay.xcodeproj`를 Xcode로 엽니다. Google의 공식 Swift Package Manager 패키지 `https://github.com/googlecast/google-cast-ios-sdk` **4.8.6**의 `GoogleCastDynamic` 제품이 자동으로 연결됩니다. 패키지 다운로드에는 인터넷이 필요합니다.
3. Xcode Settings → Accounts에서 본인 Apple 계정을 추가합니다. 유료 개발자 가입 없이 본인의 기기에서 시험하는 **Personal Team**을 선택할 수 있습니다.
4. Tooplay target → Signing & Capabilities에서 Team을 본인의 Personal Team으로 지정합니다. Bundle Identifier가 충돌하면 본인만의 값으로 바꿉니다.
5. iPhone/iPad를 USB로 연결하고 신뢰 및 개발자 모드 안내를 완료합니다. 상단 실행 대상에서 실제 기기를 선택하고 Run을 누릅니다. 처음 실행할 때 인증서 신뢰를 요청하면 기기의 설정 → 일반 → VPN 및 기기 관리에서 본인 개발자 계정을 신뢰합니다.
6. 앱에서 로컬 네트워크 접근을 허용합니다. Chromecast 및 컴퓨터와 같은 Wi-Fi에 연결합니다.

무료 Personal Team의 설치에는 기간·기기 수 등의 제한이 있습니다. 서명이 만료되면 Xcode에서 다시 실행해야 합니다. TestFlight/App Store 배포는 Apple Developer Program 가입 후 진행합니다. 이 배포본은 개인 기기 시험용이며 App Store/TestFlight 배포본이 아닙니다.

## 구현 범위와 남은 검증

- 실제 iPad에서 설치와 첫 실행 검증을 마쳤고, 0.3.1의 로컬 재생 소리는 사용자가 직접 확인했습니다. 실제 iPhone 설치, iPad의 파일 선택·영상 재생 전체 과정에 대한 별도 계측·UI 시험, 모바일에서 Chromecast로 보내는 장시간 재생은 아직 검증하지 않았습니다.
- iOS 27.2의 iPhone 17 및 iPad(10세대) 시뮬레이터에서 실제 앱의 컴퓨터 연결 화면과 세로 레이아웃을 확인했습니다. 페어링·재생·일시정지·앞으로 이동·연결 해제 UI 시험이 두 기기에서 통과했고, 별도 계측으로 Mac 배포 앱의 실제 영상 프레임 증가도 확인했습니다. 회전 및 전체 접근성 검증은 아직 실행하지 않았습니다.
- MKV/AVI 및 내장 ASS/이미지 자막은 모바일 로컬 모드에서 지원하지 않습니다. 이런 영상은 기존 데스크톱 Tooplay로 열고 컴퓨터 연결 모드를 사용합니다.
- AVFoundation의 720p 프리셋은 출력 비트레이트를 시스템이 정합니다. 데스크톱의 2.5Mbps/최대3Mbps 제한과 동일하다고 주장하지 않습니다. 실제 iOS 출력 코덱·크기·프레임 수와 장시간 Chromecast 전송을 기기에서 검증해야 합니다.
- Finder 파일 공유로 Tooplay의 Documents 폴더에 영상과 자막을 넣거나, 파일 앱에서 다른 위치의 파일을 선택할 수 있습니다. 파일 앱에서 가져온 영상은 앱의 임시 캐시에 복사됩니다. 영상 교체/닫기 및 다음 실행 때 정리합니다. 사진 보관함에서 쓰려면 먼저 파일 앱으로 저장하세요.
- 연결 토큰은 앱 메모리에만 보관하며 연결 해제 시 서버에 폐기를 요청합니다. 앱 재시작 후 새 연결 코드가 필요합니다. 마지막 컴퓨터 주소만 기기에 저장합니다.
- IPv4 사설 Wi-Fi 주소(10/172.16–31/192.168)만 입력할 수 있습니다. 원격 HTTP 요청의 리디렉션을 따라가지 않습니다. IPv6 전용 네트워크는 지원하지 않습니다.
- `NSAllowsArbitraryLoads`는 iOS 16에서 사용자가 입력한 사설 IP의 HTTP 서버에 연결하기 위한 설정입니다. 앱의 주소 검증이 사설 IPv4만 허용합니다. 인터넷 서비스를 운영하거나 영상을 외부로 업로드하지 않습니다.
- 로컬 영상 HTTP 서버는 무작위 URL로 명시적으로 등록한 파일만 제공하며 파일 전체를 메모리에 읽지 않습니다. 큰 파일은 최대64KiB씩 소켓 전송 완료에 맞춰 읽습니다.

## 개발 검증

```sh
./scripts/check.sh
TOOPLAY_INTEGRATION=1 ./scripts/check.sh
```

첫 명령은 전체 Swift 구문 검사, plist/Xcode 프로젝트 구문 검사와 Mac에서 실행 가능한 Swift 핵심·프로토콜 모델 시험을 수행합니다. 이 검사는 **iOS 앱 빌드 성공을 의미하지 않습니다**.

두 번째 명령은 같은 소스의 `URLSession` 원격 클라이언트를 실제 데스크톱 `RemoteServer`와 연결해 페어링·인증·명령·토큰 폐기를 확인하고, `NWListener` 영상 서버의 HTTP Range/HEAD/전체 스트리밍/잘못된 요청을 실제 HTTP로 확인합니다. 테스트용 상태를 사용하며 TV에는 연결하지 않습니다. `../desktop` 소스와 Node.js, 사설 LAN 주소 및 로컬 서버 실행 권한이 필요합니다.

전체 Xcode 설치 후:

```sh
./scripts/build-ios.sh all
```

이 명령은 전체 Xcode와 필요한 SDK를 먼저 확인하고, 프로젝트 설정을 그대로 복사한 임시 작업 폴더에서 빌드합니다. 전역 `xcode-select` 설정이나 원본 프로젝트의 Team/Bundle ID는 바꾸지 않습니다. `simulator` 또는 `device` 인수로 한 대상만 빌드할 수 있으며, 두 번째 인수로 소스 폴더 밖의 결과 디렉터리를 지정할 수 있습니다. 다른 위치의 Xcode는 `DEVELOPER_DIR=/path/Xcode.app/Contents/Developer`로 지정하세요.

성공하면 Simulator용 `.app.zip`, 서명하지 않은 기기용 `.xcarchive.zip`, Xcode 결과 번들·로그·파일 해시를 만듭니다. 시뮬레이터 앱은 iPhone에 설치할 수 없으며 기기용 앱은 본인 계정으로 서명해야 합니다. 개인 기기 설치는 위의 Personal Team 절차를 따르세요.

실제 네이티브 UI 리모컨 시험 절차는 `Tests/SimulatorSmoke/README.md`, 재생 검사는 `Tests/NativePlayback/README.md`, 전체화면 검사는 `Tests/Fullscreen/README.md`에 있습니다. 이전 실행 결과와 검증 한계는 [검증 요약](../docs/validation.md)을 참고하세요.

실제 재생·자막·오디오·전체화면 시험의 결과와 검증 한계는 [검증 요약](../docs/validation.md)에 정리했습니다.

최근 핵심 검사에는 연결 만료 후 재페어링, 오래된 비동기 응답 무시, 중복 서버 시작, 서버 시작 중 중지, 재시작 시 이전 영상 주소 폐기와 서버 메모리 해제 검증도 포함됩니다. 취소된 변환 파일은 정리하고, 영상 준비 중에는 기존 영상 재생 조작을 잠시 잠급니다.

프로젝트를 재생성하려면 `python3 scripts/generate-project.py`를 실행합니다. 이 명령은 프로젝트 설정을 덮어쓰므로 본인 Team/Bundle ID 변경 전 실행하세요.

참고: [Google Cast iOS 설정](https://developers.google.com/cast/docs/ios_sender), [Cast 연동](https://developers.google.com/cast/docs/ios_sender/integrate), [Apple 무료 개인 기기 개발 안내](https://developer.apple.com/support/compare-memberships/).
