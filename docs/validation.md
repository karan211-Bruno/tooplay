# Tooplay 검증 요약

검증 날짜: 2026-11-05. 이 문서는 실제 실행 결과를 요약합니다. 개인 기기 식별자·서명 정보·로컬 경로가 들어 있는 원본 로그와 개인 IPA는 저장소에 포함하지 않습니다.

## Android 0.3.2 (versionCode 4)

- APK 빌드와 JVM 테스트 6개 통과.
- Android API 34 ARM64 에뮬레이터의 기존 통합 테스트 3개 통과: 실제 영상 디코딩·재생·탐색·일시정지, 한국어 SRT 큐, TV 전송용 H.264/AAC 파일 준비, HTTP Range 응답.
- 새 전체화면 시험 1개 통과: 원본 비율/화면 채우기의 영상 크기, 세로→가로→세로 회전, 같은 재생 객체·영상·위치·자막 유지, 시스템 바 숨김/복원, 실제 뒤로 가기 키, 닫기, 실제 터치 재생·일시정지.
- 영상과 시작 위치를 함께 지정한 뒤 준비하도록 자막 적용 순서를 보완했습니다. 이 수정 뒤 기존 3개 시험을 두 차례 통과했고, 0초부터 시작하는 자막을 사용한 전체화면 시험도 통과했습니다.
- 최종 APK의 v1/v2 서명을 검사했으며 기존 0.3.0 APK와 인증서가 같습니다.
- 실물 Android 휴대폰·태블릿, 모바일에서 실제 TV 전송, 장시간 배터리·화면 잠금과 태블릿별 레이아웃은 미검증입니다.

## iPhone·iPad 0.3.2 (build 3)

- Xcode 기기용 앱 빌드 및 개인 iPad 업데이트 설치·실행 확인.
- 실제 AVPlayerLayer를 사용한 비율·재생 유지 검사 통과.
- iPad 시뮬레이터에서 전체화면, 원본 비율/화면 채우기, 회전, 닫기와 재생 유지 UI 검사 통과.
- UI 시험은 별도의 시험용 앱에서 영상을 미리 연 뒤 실제 앱의 화면·재생 코드를 사용했습니다. 시스템 파일 선택창의 전체 조작 과정과 실물 iPad의 전체화면 손동작까지 자동 검증한 것은 아닙니다.
- 0.3.1의 오디오 세션 수정과 소리 있는 시험 영상은 사용자가 개인 iPad에서 소리를 듣고 확인했습니다. 이는 자동화된 스피커 계측과 구분합니다.
- 실제 iPhone 설치 및 모바일에서 Chromecast로 전송하는 장시간 시험은 미검증입니다.

## 데스크톱 0.3.0

- 기존 Mac 배포 앱과 Android/iOS 가상 기기에서 페어링·재생·일시정지·탐색·자막 목록·연결 해제 리모컨 연동을 검증했습니다.
- 이전 데스크톱 0.2.1의 Chromecast HD 10분 전송 시험은 모바일 전송 시험과 별개입니다.
- 이 저장소를 준비하면서 실행 코드는 바꾸지 않았습니다. 이번 GitHub 등록을 위해 데스크톱 전체 테스트나 모든 OS 빌드를 다시 수행하지는 않았습니다.
- Windows/Linux용 빌드 스크립트는 있으나 0.3.0의 해당 OS 설치·실행은 미검증입니다.
